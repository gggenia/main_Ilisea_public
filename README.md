# sea1

משחק נחש קטן:

- זזים עם חיצי המקלדת.
- אוספים את כל 12 הנקודות כדי לגדול ולנצח.
- נגיעה באחד משני הכדורים האדומים פוסלת את המשחק.
- במסך הסיום אפשר ללחוץ על "תרצה לעשות עוד פעם?" ולהתחיל מחדש.
- בשלב הבא יש מסלול עם קירות.
- בשלב 3 יש 5 שאלות מתמטיקה אמריקאיות לילדים, עם תשובה נכונה אחת לכל שאלה.
- אחרי שלב 3 אפשר לעבור לשלב 4 עם 5 חידות קלות.
- אחרי שלב 4 נפתח שלב 5 חגיגי עם צליל ניצחון, נצנצים ובחירה בין עוגה לפרינגלס.
- לאחר הבחירה הפרס מופיע על השולחן.
